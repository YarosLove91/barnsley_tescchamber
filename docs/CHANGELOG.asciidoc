== [0.1] - 2026-10-15

Базовый выпуск (initial release).

=== Added
* Генерация фрактала Барнсли («папоротник») методом системы итерированных
функций (IFS) из четырёх аффинных преобразований.
* Встроенная графическая подсистема без внешних зависимостей: растеризация,
вывод в изображение и текстовый (ASCII) предпросмотр в терминале.
* Переключение графической подсистемы на этапе сборки через
`make GRAPHICS=1` / `make GRAPHICS=0` (headless) и в рантайме через
`--graphics` / `--no-graphics`.
* Аргументы командной строки: `--preview`, `--out FILE`, `--iterations N`,
`--width N`, `--height N`, `--version`, `-h`/`--help`.
* Запись результата в файл формата PPM (P3).
* Makefile: раздельная компиляция и линковка, авто-генерация зависимостей
(`-MMD -MP`), флаг `-Wextra`, пересборка при смене флагов; цели сборки,
запуска и проверки.
* Структура каталогов: исходники в `src/`, документация в `docs/`,
артефакты сборки в `build/` и `bin/`.
* Сабмодуль `scr1` (`git@github.com:syntacore/scr1.git`).
